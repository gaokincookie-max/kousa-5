# 考査週間⑤問題集

化学・生物基礎・歴史総合の学習用クイズサイトです。**合計454問**。GitHub Pagesで公開可能な静的HTMLサイトで、外部ライブラリ・ビルド作業・APIキーは必要ありません。

## 使い方

`index.html` をブラウザで開くか、GitHub Pagesの公開URLを開いてください。教科を選び、通常／変態モードや単元、出題数を設定して演習できます。四択はタップで即採点し、化学の数値問題は数値入力後に採点します。

- 化学：199問（通常161・変態38）
- 生物基礎：141問（通常113・変態28）
- 歴史総合：114問（通常85・変態29）

解説には教科書の参照ページを記載しています。学校指定の版や授業進度によって範囲が異なるため、出題範囲と解答は必ず手元の教材と照合してください。

## GitHub Pagesで公開

1. GitHubで新規**公開リポジトリ**を作成します。
2. このフォルダの **`index.html`、`favicon.svg`、`.nojekyll`、`README.md`、`.gitignore`** をリポジトリのルートにアップロードしてコミットします。
3. GitHubの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選択し、`main` / `/(root)` を指定して保存します。
4. Settings → Pagesに表示されるURLからアクセスします。

リポジトリ名が `exam-week-5` なら、通常の公開URLは `https://<GitHubユーザー名>.github.io/exam-week-5/` です。ユーザー名は自分のものに置き換えてください。

## データ保存・プライバシー

学習履歴・間違い・ブックマーク・途中経過はブラウザの `localStorage` に保存します。サーバーへ送信しません。**ブラウザを変更した場合や、ローカルHTMLからGitHub Pagesへ移動した場合は自動同期されません。** トップ画面の「学習データのバックアップ」でJSONを書き出し、移行先で読み込んでください。共有端末で使用する場合は履歴が他の利用者から見える場合があります。

## 構成

- `index.html` — 全科目の問題データ・HTML/CSS/JavaScriptを内包
- `favicon.svg` — サイトアイコン
- `.nojekyll` — GitHub PagesのJekyll処理を省略

## 改変・利用について

学校の教科書・ワークの画像は同梱していません。問題と解説は学習目的で作成したものです。第三者に公開する際は、利用する教材の著作権・引用・内容の正確性を確認してください。オープンソースライセンスは設定していません。公開リポジトリにすることと、第三者への再利用許諾は別です。


## 記述式モード (v1.4)

演習設定の「解答方式」で **4択** / **記述式** を選べます。記述式は選択肢なしで用語・年号・数値などを入力して解答します。短答として成立する問題のみ抽出します。自動採点は表記ゆれのすべてを把握できないため、表示された正答・解説に照らして「自己採点で正解に変更」できます。化学の計算問題は従来の数値入力を維持します。モードは開始した演習ごとに保存します。
